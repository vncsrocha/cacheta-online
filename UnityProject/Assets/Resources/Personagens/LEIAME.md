# Modelos 3D dos personagens

Os arquivos `.glb` dos personagens ficam aqui (o pacote glTFast importa automaticamente).
O Unity baixa sozinho os modelos do elenco quando abre o projeto (veja `Assets/Editor/BaixarPersonagens.cs`).
Para baixar tudo de novo: menu **Carteado > Baixar personagens 3D**.

O nome do arquivo é o campo `Model` do perfil, por exemplo `TioBeto.glb` para o Tio Beto.
Se o arquivo não existir, o jogo monta o personagem com formas simples.

Para ver cada chefe no próprio cenário: menu inicial > **Elenco nos cenários**.
